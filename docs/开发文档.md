## 1. 项目定位与目标

### 1.1 一句话定位

个人名片站，同时承担简历功能，用**「系统面板」**的形式整合技能、状态、经历、收藏、联系方式——类似小说里的系统面板，显示一个人的全部信息。

### 1.2 用户原始需求（原话）

> 这个网站只是单纯的名片，包含简历的作用，整合我所有会的技能，喜欢的爱好等等，主要作用是方便对自身的充分认知，更加方便对自身未来的规划。打个比方类似于小说里的系统面板显示着自己所有的信息。

### 1.3 迭代历史（重要背景，避免走回头路）

| 版本 | 设计方向 | 结果 |
|---|---|---|
| v1 dark-room | 暗色房间 + 档案物件（seed 392639615） | 被否决：太暗、太艺术、风格不对味 |
| v2 contact-sheet | 照片档案墙 / 时间线（seed 2073373282） | 被否决：不符合最初"名片 + 简历"要求，风格偏展室 |
| v3 系统面板 | page-is-the-object（seed 1994673433） | 用户初步认可后又否决：**"UI AI 感很重，太旧，用着不舒服"** |
| v4 name-as-monument（当前） | 名字纪念碑 + 全屏瓦片（seed 256556569） | 用户要求"换一个设计"后的第四次重设计，已上线 |
| v4 少图版（当前） | 同上方向；**图片 11 张 → 4 张**，首屏中间大图改文字状态面板，收藏 8 图改清单 + 2 图 | 用户反馈"一看全是图片，这个项目不需要那么多图片"后的调整，**当前线上版** |

**已否决的技术方案（不要再提）**：meark.com（溢价 20 多万）、阿里云 OSS、Cloudflare Pages（国内慢）、小程序 / Capacitor App、Astro 框架（v1.3 内容管理方向除外）。定论：**纯静态 HTML/CSS/JS + GitHub Pages**。

## 6. JS 功能（`assets/js/main.js`）

**核心机制（v2.0 与 v3 最大区别）**：所有入场动效**直接写元素的 inline style**（不是 CSS class 过渡），因为 inspect 的 headless Chrome 默认模拟 `prefers-reduced-motion: reduce`——CSS transition/animation 在 reduce 下被禁用，只有 JS 直写 style 会被 MutationObserver 计为 `scripted` 动效。

| 功能 | 实现 | 备注 |
|---|---|---|
| reveal 入场 | `IntersectionObserver`（threshold 0.15）+ IO 触发时写终态 | 目标：`.intro__col, .about__facts, .about__body, .skill-col×3, .work__name×6, .work__preview, .contact__ask, .contact__mail, .site-foot` |
| 隐藏态 | `opacity: 0` + `translateY(20px)` + `transition: opacity/transform 0.55s`；触发时 `opacity: 1; transform: none` | **reduced 时保留 0.15s 纯淡入（无位移）**——必须保留 opacity 变化，否则动效计数为 0 会被门禁判 FAIL |
| wipe 入场 | `clip-path: inset(100% 0 0 0)` → `inset(0 0 0 0)`，0.7s cubic-bezier | 目标：`.rail-left, .rail-main, .rail-side, .gallery__item×8`；**reduced 时跳过**（不隐藏） |
| hero 视差 | scroll + rAF 直写 `rail-main img` 的 `translate3d(0, y*0.06, 0)`，限 ±48px | **滚动必触发 style 写入，是动效计数的可靠兜底**（v3 同款机制） |
| work 激活 | hover / focus / click → `is-active` + 预览图 / note 切换 | 无 JS 时仍显示第一条（HTML 默认） |
| 无障碍 | `prefers-reduced-motion` 检测：reduced 只保留快速淡入，无位移、无 clip 动画 | 内容始终可见，不依赖 JS 渲染 |

**动效门禁**：实测 16+ 个元素在加载 / 滚动中移动（≥16 过 WARN 线；<8 判 FAIL still-page）。

**调试备忘**：`inspect.mjs` 的 headless Chrome 默认 `prefers-reduced-motion: reduce`，且 CSS 类过渡（transitionrun/animationstart）在该环境不被计数——只认 JS 直写 style（scripted）。调试脚本 `D:\07-Code\MeArks\_debug_motion.mjs`（临时件，可删）注入 MOTION_RECORDER 验证此机制。
